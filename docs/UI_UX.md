## 옛 화면의 문제

- **시선이 위아래로 오간다.** 카드는 화면 아래에 있는데, 고른 순서와 링크 배율은 화면 맨 위에 있었습니다.
- **고르기 전에는 결과를 알 수 없다.** 카드가 이번 순서에서 링크될지, 반응을 일으킬지는 머릿속으로 계산해야 했습니다.
- **카드가 크고 글이 많다.** 손패 8장이 각각 설명문을 달고 있어 한 화면에 정보가 너무 많았습니다.
- **피해를 예측하기 어렵다.** 적 예고 숫자는 있었지만, 내 공격 뒤에 적 HP가 얼마 남는지는 따로 계산해야 했습니다.
- **편성 화면이 너무 길다.** 캐릭터 6명 카드마다 스킬 5개가 펼쳐져 있어 스크롤이 길었고, 시작 버튼은 모바일에서 맨 아래에 있었습니다.

## 원칙과 반영

### 1. 결정과 결과는 한곳에

행동과 관련된 정보는 손패 바로 위에 모읍니다.

- 하단 독은 두 줄입니다.
  - 윗줄: 체인 트랙(고른 순서, 링크 배율, 반응), `NEXT`(다음에 받아야 할 성속), 성진
  - 아랫줄: 손패, 체인 수치, 시전 버튼
- 상단 HUD는 뒤로가기, 층과 장소, 라운드, 속도, 기록, 도움말만 남긴 얇은 막대가 되었습니다.

### 2. 고르기 전에 결과를 보여 준다

계산은 화면이 대신합니다.

- **링크 예고**: 카드마다 "지금 넣으면 어떻게 되는지"를 띠로 표시합니다. 유형은 `LINK 2 ×1.25`, `일식 ×1.6`(반응), `끊김` 세 가지입니다. 이미 고른 카드는 실제 순서 기준으로 보여 줍니다.
- **HP 예측**: 지금 계획을 복제한 전투에 실제로 돌려 보고, 각 HP 막대에 깎일 구간을 빗금으로 겹칩니다.
  - 적은 `80 → 69`처럼 남을 HP를 보여 주고, 쓰러질 적은 `→ 처치`로 표시합니다.
  - 아군도 적의 공격까지 반영한 라운드 끝 HP를 보여 줍니다.
  - 무작위 대상 스킬도 같은 난수 상태로 계산하므로 예측과 결과가 일치합니다.

### 3. 정보는 계층으로

카드에는 판단에 필요한 최소한만 남기고, 자세한 내용은 설명 패널로 옮겼습니다.

- **카드**: 비용, 유형 태그, 이름, 받는 성속과 넘기는 성속, 링크 예고
- **설명 패널**: 카드에 마우스를 올리거나 포커스하면 무대 아래 가운데에 뜹니다. 시전자, 비용, 받는 성속과 넘기는 성속, 설명, 링크 결과를 문장으로 보여 주고, 성진이 부족하면 그 이유도 알려 줍니다.
- **모바일**: 이름과 설명 한 줄만 보여 줍니다. 링크 정보는 이미 카드 띠에 있습니다.

### 4. 엄지 영역과 반복 조작

- **모바일 전투**: 손패를 2열 격자로 접었습니다. 시전 버튼과 체인 수치는 화면 아래에 붙어 스크롤해도 항상 보입니다.
- **모바일 편성**: 화면 아래 고정 막대에 편성 4칸과 시작 버튼을 둡니다.
- **단축키**: `1~8` 카드, `Space` 시전, `Backspace` 마지막 취소, `R` 초기화, `L` 기록. 마우스를 쓰는 기기에서만 카드 모서리에 번호를 표시합니다.

### 5. 색만으로 말하지 않는다

- 링크 예고는 색과 함께 글자(`LINK`, `끊김`, 반응 이름)를 씁니다.
- 체인 트랙의 끊김은 빨간 점선에 `끊김` 글자를 함께 둡니다.
- 성속은 늘 기호(☉ ☾ ✺ ☄ ◉ ✦)와 색을 함께 씁니다.

### 6. 편성: 고르기와 읽기를 나눈다

- **왼쪽, 로스터**: 초상 타일 3×2. 누르면 편성에 넣거나 빼고, 마우스를 올리면 상세를 봅니다.
- **가운데, 상세**: 큰 초상, 콘셉트, 능력치 막대, 스킬 5개(유형, 성속 흐름, 설명), 편성 버튼
- **오른쪽, 팀 패널**: 4칸, 궁합(최대 체인, 반응, 추천 순서), 시작 버튼

## 배경

야경 도시 한 가지만 쓰던 배경을, 층마다 시간대와 날씨가 다른 장소로 바꿨습니다. 건물은 빗속 네온 운하에만 남겼습니다.

| 화면 | 장소 | 시간·날씨 |
| --- | --- | --- |
| 메인·편성 | 노을 해안: 물 위의 바위 기둥, 거울 같은 수면 | 해 질 녘 |
| 1층 | 새벽 안개 초원: 활엽수 숲, 선돌, 완만한 언덕 | 새벽 안개 |
| 2층 | 빗속 네온 운하: 젖은 아스팔트, 네온 창, 가로등 | 밤, 비, 번개 |
| 3층 | 모래바람 사구: 사구 능선, 바위 대지 | 한낮, 모래바람 |
| 4층 | 오로라 설원: 침엽수, 눈 덮인 봉우리 | 밤, 눈, 오로라 |
| 5층 | 부서진 하늘섬: 부러진 기둥, 떠 있는 바위섬 | 일식, 불씨 |

낮 장면에서는 하늘이 밝기 때문에 블룸을 줄이고 노출을 따로 맞췄습니다.
