# 성좌술사 (Starweaver)

별과 마법을 테마로 한 2.5D 턴제 전투 프로토타입입니다. 술사 6명 중 4명을 편성하고, 술사마다 주문 9개 중 5개를 장착합니다. 매 라운드 술사마다 장착한 주문 중 2장을 뽑습니다. 그중 무엇을 어떤 순서로 쓸지 정하면, 앞 스킬이 내보낸 성속을 다음 스킬이 받을 때 링크가 이어집니다. 링크가 이어지면 체인 배율과 성좌 반응이 발동합니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 전투 로직 단위 테스트
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

WebGL이 필요합니다. 배경, 바닥 반사, 블룸, VFX는 three.js로 그립니다.

## 덱

링크와 반응 위에 두 갈래의 자원이 얹힙니다. 적에게 거는 **각인**과 술사마다 하나씩 있는 **고유 중첩**입니다. 각 술사의 패시브가 이 둘을 잇기 때문에, 한 술사가 깐 각인이 다른 술사의 중첩을 채웁니다.

### 스킬 구조

스킬은 림버스 컴퍼니식으로 여러 줄의 효과를 가집니다. 순서는 이렇습니다.

1. **[전투 시작 시]** 이번 턴 쓰기로 한 스킬이면, 누구의 시전보다 먼저 발동합니다(성진이 모자라 못 쓰는 스킬은 빠짐).
2. **[사용 시]** 타격 전에 일어나는 효과. 중첩 소모, 조건부 획득 등.
3. **타격 Ⅰ·Ⅱ·Ⅲ…** 단계마다 위력, 조건부 피해 증가, **[적중 시]** 효과가 따로 있습니다. 점선 단계는 조건이 맞을 때만 나가고 아니면 불발입니다.
4. **[시전 후]**, **[처치 시]** 마지막 효과. 처치 시는 시전당 한 번.

주황 꼬리표(예: `[대상 화상 위력 + 태양핵 5 이상]`)는 조건입니다. 설명은 `src/data/describe.ts`가 주문 데이터에서 자동으로 만들기 때문에 실제 효과와 어긋나지 않습니다. 전투에서는 이름표에 Ⅰ Ⅱ Ⅲ 단계가 차례로 켜지고, 대상 위로 단계 숫자가 크게 뜨며, 근접은 단계마다 자세와 베기 모양이, 원거리는 마지막 단계가 광선으로 바뀝니다.

### 각인 (적에게, `위력·횟수`)

같은 각인을 다시 걸면 위력과 횟수가 함께 쌓입니다(위력 최대 20, 횟수 최대 10). 주문 설명의 "화상 2·3"은 위력 2, 횟수 3입니다.

| 각인 | 효과 |
|---|---|
| 화상 ♨ | 라운드가 끝날 때 위력만큼 피해, 횟수 -1 |
| 균열 ✧ | 아군에게 맞을 때마다 위력만큼 방어 무시 추가 피해, 횟수 -1 |
| 잠식 ◐ | 적이 움직일 때마다 위력만큼 피해, 횟수 -1 |
| 진동 ≋ | 쌓아 두었다가 터뜨림. 터질 때 위력 8 이상이면 기절 |
| 월영 ☾ | 이 적을 때린 아군이 위력만큼 회복, 횟수 -1 |

일부 주문은 각인을 **터뜨리거나**(burst), 다른 각인으로 **바꾸거나**(convert), **삼킵니다**(devour).

### 고유 중첩과 패시브

| 술사 | 패시브 | 고유 중첩 | 쓰는 주문 |
|---|---|---|---|
| 솔레아 | 태양심장: 화상 걸린 적을 때리면 +1 | 태양핵 ☉ (최대 6) | 초신성 창이 모두 태워 1당 +60%, 이어서 화상을 터뜨림 |
| 벨라 | 사냥꾼의 눈: 균열 걸린 적을 맞히면 +1, 1당 피해 +6% | 조준 ⌖ (최대 6) | 종언의 별이 모두 써서 1당 +70%, 이어서 균열을 터뜨림 |
| 루네 | 밀물: 아군이 회복할 때마다 +1 | 만조 ≈ (최대 10) | 그믐의 종장이 전원 회복 후 모두 풀어 1당 +20% |
| 녹스 | 포식: 화상·잠식 피해가 날 때마다 +1, 1당 피해 +5% | 허기 ◉ (최대 10) | 심연의 만찬이 잠식·균열을 삼켜 위력으로 바꾸고 1당 +10% |
| 아스트라 | 불굴: 보호막을 얻거나 맞을 때마다 +1, 반격 +2씩 | 불굴 ⛉ (최대 8) | 방패 강타가 모두 써서 1당 +12%, 진동을 새김 |
| 네비아 | 증폭자: 거는 각인 위력 +1 | (아군에게) 공명파동 ∿ (최대 3) | 다음 시전의 피해·회복·보호막 +20%(중첩당) |

시너지 예: 솔레아가 화상을 깔면 녹스의 허기가 차고, 녹스의 부식의 씨앗이 그 화상을 1.5배 잠식으로 바꿉니다. 벨라의 연사가 균열을 쌓으면 모두의 타격에 고정 피해가 붙고, 녹스가 그 균열째 먹어 치웁니다. 월영을 걸어 두면 때릴 때마다 회복이 일어나 루네의 만조가 찹니다.

고유 중첩은 눈으로 보이게 했습니다. 쌓일 때마다 술사 뒤 오라가 커지고 상승음이 높아지며, 분대 칸 게이지에 이름과 칸이 차오르고 절반을 넘으면 READY가 뜹니다. 주문 카드에는 지금 배율(예: ☉4 ×3.4)이 붙고, 해방하면 컷인과 함께 시간이 잠깐 느려집니다.

속성 공명은 그대로입니다. 시전마다 내보낸 성속이 1씩 쌓이고(속성별 최대 10), 공명 주문이 그 값을 씁니다.

편성 화면의 추천 덱(`src/data/decks.ts`)은 팀과 주문서를 한 번에 맞춥니다.

| 덱 | 운영 | 핵심 술사 |
|---|---|---|
| 초신성 폭주 | 화상으로 태양핵을 채우고 조준과 함께 초신성 창·종언의 별로 끝냄 | 솔레아, 벨라 |
| 균열 사냥 | 연타로 균열을 쌓아 고정 피해를 얹고 녹스가 균열·잠식을 삼킴 | 벨라, 녹스 |
| 태양 공명 | 태양을 내보낼 때마다 공명이 쌓이고 화상 걸린 적에게 점점 강해짐 | 솔레아, 네비아 |
| 만조 해방 | 월영으로 때릴 때마다 회복해 만조를 채우고 그믐의 종장으로 풀어냄 | 루네 |
| 공허 포식 | 잠식과 지연 폭격을 깔아 허기를 채우고 메아리로 앞당겨 터뜨림 | 녹스 |
| 성채 반격 | 불굴을 쌓아 반격·방패 강타로 갚고 진동을 모아 별의 심판으로 기절 | 아스트라 |

## 구조

- `src/core/`: 전투 규칙(DOM 의존 없음). 링크·체인, 전투 상태머신, 손패 뽑기, 팀 궁합 분석, 런 진행과 저장
- `src/data/`: 성속·반응, 주문 54종, 술사 6명(주문서 9개씩), 추천 덱 6종, 적, 층 구성, 보상
- `src/render/three/`: 2.5D 무대
  - `environment.ts`: 층별 배경 조립. 노을 해안, 안개 초원, 네온 운하, 사구, 오로라 설원, 하늘섬
  - `env/`: 배경 조각
    - `sky.ts`: 일러스트풍 하늘(세 색 그라데이션, 셀 구름, 별, 별의 강, 오로라, 해·달·일식)
    - `celestial.ts`: 별자리, 하늘의 마법진·아스트롤라베, 빛기둥, 별똥별
    - `arcana.ts`: 떠다니는 수정, 별가루, 땅의 룬 마법진
    - `layers.ts`: 먼 능선 실루엣 층
    - `toon.ts`, `magicCircle.ts`: 셀 셰이딩 재질, 셰이더 마법진
    - `terrain.ts`: 높이맵 지형
    - `props.ts`: 바위, 나무, 기둥, 떠 있는 섬
    - `vegetation.ts`: 바람에 흔들리는 풀
    - `water.ts`: 반사되는 바다, 구름 바다
    - `city.ts`: 네온 운하
    - `weather.ts`: 비, 안개, 입자
    - `maps.ts`: 절차적 표면 질감
  - `quality.ts`: 그래픽 품질(자동/높음/낮음). 높음은 그림자, MSAA, 빛줄기, 풀이 더 많다
  - `fx.ts`: 스킬 VFX
  - `stage.ts`: 카메라, 후처리, 캐릭터 판
- `src/render/rig.ts`: 술사 6명의 검은 실루엣 일러스트(SVG)를 뼈대 조각(머리·머리카락·팔·몸·다리·망토)으로 나눈 것
- `src/render/three/puppet.ts`: 조각을 판으로 세운 컷아웃 인형. 숨쉬기, 무기별 공격(찌르기·들어올리기·사격·베기·들이받기), 힘 모으기, 피격, 쓰러짐, 승리 자세
- `src/render/figures.ts`: 적 형상(SVG). 무대에서 몸을 젖혔다 덮치고, 맞으면 찌그러지고, 쓰러지면 돌며 사라진다
- `src/audio/sound.ts`: 효과음과 배경 음악. 마법 소리는 FM 합성 종소리(성속마다 음 높이가 다름), 배경 음악은 장면별 화음 진행 위에 패드·베이스·아르페지오·북을 실시간으로 엮는다
- `src/ui/`: 화면. 메인 → 편성 → 성도(지도) → 전투 → 보상 → 결과
- `tests/core/`: Vitest 테스트

기획과 로드맵은 [docs/PLAN.md](docs/PLAN.md)에, UI/UX 분석과 개편안은 [docs/UI_UX.md](docs/UI_UX.md)에 있습니다.
