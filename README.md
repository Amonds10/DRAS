# 성좌술사 (Starweaver)

별과 마법을 테마로 한 2.5D 턴제 전투 프로토타입입니다. 술사 6명 중 4명을 편성해 싸웁니다. 전투는 스타레일식 속도 기반 턴제입니다. 술사마다 일반 공격·전투 스킬·필살기가 있고, 적의 약점 속성을 찔러 강인도를 깎아 격파합니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 전투 로직 단위 테스트
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

WebGL이 필요합니다. 배경, 바닥 반사, 블룸, VFX는 three.js로 그립니다.

## 전투

- **행동 순서**: 유닛마다 속도가 있고(행동 값 = 10000 / 속도), 가장 먼저 차례가 오는 유닛이 움직입니다. 화면 왼쪽에 앞으로의 순서가 보입니다.
- **술사 차례**: 일반 공격(Q, 성진 +1) 또는 전투 스킬(E, 성진 -1)을 씁니다. 성진은 팀 공용이고 최대 5개입니다.
- **필살기**: 공격하거나 맞으면 에너지가 찹니다. 가득 차면 누구의 차례든 끼어들어 쓸 수 있고(1~4), 차례를 넘기지 않습니다.
- **약점과 격파**: 적마다 약점 속성이 있습니다. 약점 속성 술사가 때리면 강인도가 깎이고, 0이 되면 격파됩니다. 격파된 적은 추가 피해를 받고 행동이 25% 늦춰지며 다음 차례를 잃고, 그 차례에 강인도를 되찾습니다. 속성마다 격파 효과가 다릅니다(태양 화상, 달 월영·약화, 성운 각인 증폭, 혜성 균열, 공허 잠식, 별빛 진동).
- **화면**: 체력·강인도·에너지·고유 중첩·상태는 캐릭터 발밑에 붙습니다. 캐릭터를 누르면 강조되고 오른쪽에 상세 정보(능력치, 상태와 설명, 패시브, 세 능력)가 뜹니다. 적을 누르면 그 적을 노립니다.

### 술사 능력

능력 설명은 스타레일식 문장으로 썼습니다. 피해 수치는 공격력 %입니다. `tests/core/abilities.test.ts`가 설명 속 공격력 %가 데이터와 맞는지 확인합니다.

| 술사 | 일반 공격 | 전투 스킬 | 필살기 |
|---|---|---|---|
| 솔레아 (태양) | 새벽 찌르기 | 홍염 연격 | 초신성 창 |
| 루네 (달) | 초승 칼날 | 월광 베일 | 그믐의 종장 |
| 네비아 (성운) | 성흔 산포 | 공명 증폭 | 원초의 빛 |
| 벨라 (혜성) | 유성 저격 | 혜성 난사 | 종언의 별 |
| 녹스 (공허) | 공허의 손길 | 부식의 씨앗 | 심연의 만찬 |
| 아스트라 (별빛) | 방패 강타 | 별의 성채 | 별의 심판 |

### 각인 (적에게, `위력·횟수`)

같은 각인을 다시 걸면 위력과 횟수가 함께 쌓입니다(위력 최대 20, 횟수 최대 10). 주문 설명의 "화상 2·3"은 위력 2, 횟수 3입니다.

| 각인 | 효과 |
|---|---|
| 화상 ♨ | 적의 차례가 시작될 때 위력만큼 피해, 횟수 -1 |
| 균열 ✧ | 아군에게 맞을 때마다 위력만큼 방어 무시 추가 피해, 횟수 -1 |
| 잠식 ◐ | 적이 움직일 때마다 위력만큼 피해, 횟수 -1 |
| 진동 ≋ | 쌓아 두었다가 터뜨림. 터질 때 위력 8 이상이면 기절 |
| 월영 ☾ | 이 적을 때린 아군이 위력만큼 회복, 횟수 -1 |

일부 주문은 각인을 **터뜨리거나**(burst), 다른 각인으로 **바꾸거나**(convert), **삼킵니다**(devour).

### 고유 중첩과 패시브

| 술사 | 패시브 | 고유 중첩 | 쓰는 능력 |
|---|---|---|---|
| 솔레아 | 태양심장: 화상 걸린 적을 때리면 +1 | 태양핵 ☉ (최대 6) | 초신성 창이 모두 태워 1당 +50%, 이어서 화상을 터뜨림 |
| 벨라 | 사냥꾼의 눈: 균열 걸린 적을 맞히면 +1, 1당 피해 +6% | 조준 ⌖ (최대 6) | 종언의 별이 모두 써서 1당 +60%, 이어서 균열을 터뜨림 |
| 루네 | 밀물: 아군이 회복할 때마다 +1 | 만조 ≈ (최대 10) | 그믐의 종장이 전원 회복 후 모두 풀어 1당 +15% |
| 녹스 | 포식: 화상·잠식 피해가 날 때마다 +1, 1당 피해 +5% | 허기 ◉ (최대 10) | 심연의 만찬이 잠식·균열을 삼켜 위력으로 바꾸고 1당 +8% |
| 아스트라 | 불굴: 보호막을 얻거나 맞을 때마다 +1, 반격 +2씩 | 불굴 ⛉ (최대 8) | 별의 성채의 반격에 실림 |
| 네비아 | 증폭자: 거는 각인 위력 +1 | (아군에게) 공명파동 ∿ (최대 3) | 다음 행동의 피해·회복·보호막 +20%(중첩당) |

편성 화면의 추천 팀(`src/data/decks.ts`)은 4명을 한 번에 맞춥니다: 초신성 폭주, 균열 사냥, 잿불 증폭, 만조 해방, 공허 포식, 성채 반격.

## 구조

- `src/core/`: 전투 규칙(DOM 의존 없음). 속도 기반 행동 순서, 성진·에너지, 강인도·격파, 런 진행과 저장, 밸런스용 자동 플레이
- `src/data/`: 성속·상태, 능력 18종(술사마다 일반 공격·전투 스킬·필살기), 술사 6명, 추천 팀 6종, 적(속도·강인도·약점), 층 구성, 보상
- `src/render/three/`: 2.5D 무대
  - `environment.ts`: 층별 배경 조립. 노을 해안, 안개 초원, 네온 운하, 사구, 오로라 설원, 하늘섬
  - `env/`: 배경 조각
    - `sky.ts`: 일러스트풍 하늘(세 색 그라데이션, 셀 구름, 별, 별의 강, 오로라, 해·달·일식)
    - `celestial.ts`: 별자리, 하늘의 마법진·아스트롤라베, 빛기둥, 별똥별
    - `arcana.ts`: 떠다니는 수정, 별가루, 땅의 룬 마법진
    - `layers.ts`: 먼 능선 실루엣 층
    - `toon.ts`, `magicCircle.ts`: 셀 셰이딩 재질, 셰이더 마법진
    - `terrain.ts`: 높이맵 지형
    - `props.ts`: 바위, 나무, 기둥, 떠 있는 섬
    - `vegetation.ts`: 바람에 흔들리는 풀
    - `water.ts`: 반사되는 바다, 구름 바다
    - `city.ts`: 네온 운하
    - `weather.ts`: 비, 안개, 입자
    - `maps.ts`: 절차적 표면 질감
  - `quality.ts`: 그래픽 품질(자동/높음/낮음). 높음은 그림자, MSAA, 빛줄기, 풀이 더 많다
  - `fx.ts`: 스킬 VFX
  - `stage.ts`: 카메라, 후처리, 캐릭터 판
- `src/render/rig.ts`: 술사 6명의 검은 실루엣 일러스트(SVG)를 뼈대 조각(머리·머리카락·팔·몸·다리·망토)으로 나눈 것
- `src/render/three/puppet.ts`: 조각을 판으로 세운 컷아웃 인형. 숨쉬기, 무기별 공격(찌르기·들어올리기·사격·베기·들이받기), 힘 모으기, 피격, 쓰러짐, 승리 자세
- `src/render/figures.ts`: 적 형상(SVG). 무대에서 몸을 젖혔다 덮치고, 맞으면 찌그러지고, 쓰러지면 돌며 사라진다
- `src/audio/sound.ts`: 효과음과 배경 음악. 마법 소리는 FM 합성 종소리(성속마다 음 높이가 다름), 배경 음악은 장면별 화음 진행 위에 패드·베이스·아르페지오·북을 실시간으로 엮는다
- `src/ui/`: 화면. 메인 → 편성 → 성도(지도) → 전투 → 보상 → 결과
- `tests/core/`: Vitest 테스트

기획과 로드맵은 [docs/PLAN.md](docs/PLAN.md)에, UI/UX 분석과 개편안은 [docs/UI_UX.md](docs/UI_UX.md)에 있습니다.
