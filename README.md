# 성좌술사 (Starweaver)

별과 마법을 테마로 한 2.5D 턴제 전투 프로토타입입니다. 술사 6명 중 4명을 편성합니다. 매 라운드 네 술사의 시전 순서를 정해 한꺼번에 실행하는데, 앞 스킬이 내보낸 성속을 다음 스킬이 받으면 링크가 이어져 체인 배율과 성좌 반응이 터집니다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # 전투 로직 단위 테스트
npm run build    # 타입 검사 + 배포용 빌드 (dist/)
```

WebGL이 필요합니다. 배경, 바닥 반사, 블룸, VFX는 three.js로 그립니다.

## 전투

- **고정 스킬 4개**: 술사마다 스킬 4개가 전투 내내 모두 보입니다. 카드 뽑기는 없고, 성진 비용과 **쿨타임**(쓴 뒤 쉬는 라운드 수)으로 제한됩니다.
- **라운드 계획**: 아래 명령 패널에서 술사(1~4)를 고르고 스킬(Q W E R)을 누르면 위쪽 체인 트랙에 순서대로 쌓입니다. 시전(Space)하면 순서대로 나가고, 이어서 적이 행동합니다.
- **링크**: 스킬마다 받는 성속 → 넘기는 성속이 있습니다. 앞 스킬이 넘긴 성속을 다음 스킬이 받으면 링크가 이어져 배율이 ×1.25 → ×1.6 → ×2로 오르고, 특정 조합은 성좌 반응(일식, 월몰, 블랙홀, 유성우, 초신성, 홍염, 조수)을 일으킵니다. 넷이 모두 이어지면 성좌 완성.
- **화면**: 스킬 버튼마다 지금 넣으면 링크·반응·끊김 중 무엇이 되는지 표시됩니다. 체력·상태·고유 중첩은 캐릭터 발밑에 있고, 캐릭터를 누르면 강조되며 오른쪽에 상세 정보(상태 설명, 패시브, 스킬 4개와 쿨타임)가 뜹니다. 적을 누르면 집중 대상이 됩니다.

### 술사 스킬

설명은 문장형으로 손으로 썼고, `tests/core/battle.test.ts`가 설명의 첫 "위력 N"이 데이터와 맞는지 확인합니다.

| 술사 | 스킬 4개 (받음 → 넘김) |
|---|---|
| 솔레아 | 여명 찌르기 (● → ☉), 항성 응축 (◉ → ☉), 홍염 연격 (✺ → ☉), 초신성 창 (☄ → ☉) |
| 루네 | 초승 칼날 (☉ → ☾), 월광 베일 (● → ☾), 월흔 (◉ → ☾), 그믐의 종장 (✺ → ☾) |
| 네비아 | 성운 안개 (☄ → ✺), 별의 십일조 (● → ✺), 공명 증폭 (☾ → ✺), 원초의 빛 (☉ → ✺) |
| 벨라 | 유성 저격 (● → ☄), 산탄 유성 (☾ → ☄), 혜성 난사 (☉ → ☄), 종언의 별 (◉ → ☄) |
| 녹스 | 흡수 (● → ◉), 공허의 손길 (☾ → ◉), 부식의 씨앗 (✺ → ◉), 심연의 만찬 (☄ → ◉) |
| 아스트라 | 방패 강타, 성좌 반향, 별의 성채, 별의 심판 (모두 아무 성속 → 받은 그대로) |

### 각인 (적에게, `위력·횟수`)

같은 각인을 다시 걸면 위력과 횟수가 함께 쌓입니다(위력 최대 20, 횟수 최대 10). 주문 설명의 "화상 2·3"은 위력 2, 횟수 3입니다.

| 각인 | 효과 |
|---|---|
| 화상 ♨ | 라운드가 끝날 때 위력만큼 피해, 횟수 -1 |
| 균열 ✧ | 아군에게 맞을 때마다 위력만큼 방어 무시 추가 피해, 횟수 -1 |
| 잠식 ◐ | 적이 움직일 때마다 위력만큼 피해, 횟수 -1 |
| 진동 ≋ | 쌓아 두었다가 터뜨림. 터질 때 위력 8 이상이면 기절 |
| 월영 ☾ | 이 적을 때린 아군이 위력만큼 회복, 횟수 -1 |

일부 주문은 각인을 **터뜨리거나**(burst), 다른 각인으로 **바꾸거나**(convert), **삼킵니다**(devour).

### 고유 중첩과 패시브

| 술사 | 패시브 | 고유 중첩 | 쓰는 스킬 |
|---|---|---|---|
| 솔레아 | 태양심장: 화상 걸린 적을 때리면 +1 | 태양핵 ☉ (최대 6) | 초신성 창이 모두 태워 1당 +60%, 이어서 화상을 터뜨림 |
| 벨라 | 사냥꾼의 눈: 균열 걸린 적을 맞히면 +1, 1당 피해 +6% | 조준 ⌖ (최대 6) | 종언의 별이 모두 써서 1당 +70%, 이어서 균열을 터뜨림 |
| 루네 | 밀물: 아군이 회복할 때마다 +1 | 만조 ≈ (최대 10) | 그믐의 종장이 모두 풀어 1당 +20% |
| 녹스 | 포식: 화상·잠식 피해가 날 때마다 +1, 1당 피해 +5% | 허기 ◉ (최대 10) | 심연의 만찬이 잠식·균열을 삼켜 위력으로 바꾸고 1당 +10% |
| 아스트라 | 불굴: 보호막을 얻거나 맞을 때마다 +1, 반격 +2씩 | 불굴 ⛉ (최대 8) | 방패 강타가 모두 실어 1당 +12% |
| 네비아 | 증폭자: 거는 각인 위력 +1 | (아군에게) 공명파동 ∿ (최대 3) | 다음 시전의 피해·회복·보호막 +20%(중첩당) |

편성 화면의 추천 팀(`src/data/decks.ts`)은 4명과 링크 순서 예시를 함께 보여 줍니다: 초신성 폭주, 균열 사냥, 잿불 증폭, 만조 해방, 공허 포식, 성채 반격.

## 구조

- `src/core/`: 전투 규칙(DOM 의존 없음). 링크·체인, 라운드 상태머신, 쿨타임, 팀 궁합 분석, 런 진행과 저장, 밸런스용 자동 계획(빔 탐색)
- `src/data/`: 성속·반응·상태, 스킬 24종(술사마다 4개), 술사 6명, 추천 팀 6종, 적, 층 구성, 보상
- `src/render/three/`: 2.5D 무대
  - `environment.ts`: 층별 배경 조립. 노을 해안, 안개 초원, 네온 운하, 사구, 오로라 설원, 하늘섬
  - `env/`: 배경 조각
    - `sky.ts`: 일러스트풍 하늘(세 색 그라데이션, 셀 구름, 별, 별의 강, 오로라, 해·달·일식)
    - `celestial.ts`: 별자리, 하늘의 마법진·아스트롤라베, 빛기둥, 별똥별
    - `arcana.ts`: 떠다니는 수정, 별가루, 땅의 룬 마법진
    - `layers.ts`: 먼 능선 실루엣 층
    - `toon.ts`, `magicCircle.ts`: 셀 셰이딩 재질, 셰이더 마법진
    - `terrain.ts`: 높이맵 지형
    - `props.ts`: 바위, 나무, 기둥, 떠 있는 섬
    - `vegetation.ts`: 바람에 흔들리는 풀
    - `water.ts`: 반사되는 바다, 구름 바다
    - `city.ts`: 네온 운하
    - `weather.ts`: 비, 안개, 입자
    - `maps.ts`: 절차적 표면 질감
  - `quality.ts`: 그래픽 품질(자동/높음/낮음). 높음은 그림자, MSAA, 빛줄기, 풀이 더 많다
  - `fx.ts`: 스킬 VFX
  - `stage.ts`: 카메라, 후처리, 캐릭터 판
- `src/render/rig.ts`: 술사 6명의 검은 실루엣 일러스트(SVG)를 뼈대 조각(머리·머리카락·팔·몸·다리·망토)으로 나눈 것
- `src/render/three/puppet.ts`: 조각을 판으로 세운 컷아웃 인형. 숨쉬기, 무기별 공격(찌르기·들어올리기·사격·베기·들이받기), 힘 모으기, 피격, 쓰러짐, 승리 자세
- `src/render/figures.ts`: 적 형상(SVG). 무대에서 몸을 젖혔다 덮치고, 맞으면 찌그러지고, 쓰러지면 돌며 사라진다
- `src/audio/sound.ts`: 효과음과 배경 음악. 마법 소리는 FM 합성 종소리(성속마다 음 높이가 다름), 배경 음악은 장면별 화음 진행 위에 패드·베이스·아르페지오·북을 실시간으로 엮는다
- `src/ui/`: 화면. 메인 → 편성 → 성도(지도) → 전투 → 보상 → 결과
- `tests/core/`: Vitest 테스트

기획과 로드맵은 [docs/PLAN.md](docs/PLAN.md)에, UI/UX 분석과 개편안은 [docs/UI_UX.md](docs/UI_UX.md)에 있습니다.
